# LÓGOS AI Privacy Notice

**Last Updated:** July 2026

LÓGOS AI is a sovereign, local-first artificial intelligence command center. We believe that your thoughts, data, and workflows should belong entirely to you.

## 1. Zero Telemetry Promise
LÓGOS AI contains **zero telemetry**, tracking pixels, analytics hooks, or remote crash reporting. We do not collect metrics on how you use the software. No usage data is transmitted to us or any third party.

## 2. Local-First Data Storage
All data generated by or provided to LÓGOS AI remains exclusively on the machine where it is installed.
- **Chat Histories:** Stored in a local SQLite database (the "Memory Palace").
- **Uploaded Artifacts:** Stored in the local file system.
- **Configurations:** Kept locally in environment variables and configuration files.

## 3. External API Usage
If you configure LÓGOS AI to use remote APIs (e.g., OpenAI, Anthropic), your prompts and uploaded files will be transmitted directly from your server to those third-party providers. LÓGOS AI does not intercept or proxy this traffic through our servers. Please review the privacy policies of any third-party model providers you choose to integrate.

When using local models (e.g., via Ollama or ComfyUI), your data never leaves your local network.

## 4. Data Deletion and Retention
You have full control over your data.
- **Clearing Sessions:** You can delete individual chat sessions or memories directly through the user interface.
- **Nuclear Option:** To completely erase all LÓGOS AI data, you can delete the SQLite database file (`backend/data/database.sqlite`) and the `uploads`/`workspace` directories.

## 5. Security Boundary
While LÓGOS AI is designed with strict file-system jailing and CORS rules to prevent malicious agent behavior or cross-site attacks, it is intended to be run in trusted, isolated environments (e.g., a local desktop or private LAN). Exposing LÓGOS AI directly to the public internet without an external authentication proxy is not recommended.
